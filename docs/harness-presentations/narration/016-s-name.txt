This layer is called an engineering harness. Remember the clutter at the code layer? The harness is a simple view over all of that complexity. When you want to encode a backpressure check, or remove a friction, this is the obvious place. It's the one place the agent looks to see what this environment can do. If a feature's missing, maybe it should add it. If one's weak, improve it. There's no more question about where improvements to your environment go.
