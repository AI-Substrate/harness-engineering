## T009 — semantic rollup (AC-07)

`fleet-evidence.ts` gains a per-lane `FleetLaneSemantics` and a fleet-level `FleetSemantics`, computed **purely from the raw segments' `artifact` events + `rollup.flow_stage_time_s`** in `laneSemantics(segs)` (wired into `buildLane`) and aggregated in `fleetSemantics(lanes)`. Dimensions: review `findings` by severity, the consecutive-deduped `verdicts` path + `fix_cycles` (`FIX_REQUIRED→APPROVE` adjacencies), `plan_phases`/`plan_cs`, `workshop_decisions`, flight-plan `nodes`/`nodes_done`/`chores_*`, and `flow_stage_time_s`. Counts dedupe by artifact `path` (latest snapshot per file) so a re-saved artifact never multiplies; the verdict path is NOT path-deduped (a FIX_REQUIRED→APPROVE re-save IS the signal).

**The honesty invariant** (hard req #1): `semantics_measured` is `false` on a lane with no artifact/flow-stage capture, and that lane **omits every dimension — never a `0`**. Each dimension is emitted only when its artifact TYPE was captured, so a lane that saw a plan but not the review reports `plan_phases` and NO `findings`. Side-channel (ledger/ref) lanes have no event stream → `blindLaneSemantics()`; fleet semantics recompute after `enrichOrphans` promotes orphans.
