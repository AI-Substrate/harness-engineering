# Research Dossier: Systemic Telemetry Repair

**Generated**: 2026-07-20T03:53:30Z
**Query**: "Repair systemic telemetry using preserved real historical sessions as the mandatory end-to-end oracle; stop rather than substitute fake data; exclude the local alternate-Claude corpus."
**Effort**: Deep
**Tools**: Standard (local source/Git reads and bounded allowlisted structural parsers; no network or workers)
**Evidence**: 15 current sources · 5 historical sources · 3 access-controlled evidence sets

## The Ask

Repair the telemetry pipeline defects exposed by a real multi-stream agent build. The repair must prove current RED and repaired GREEN against the same immutable historical sessions; synthetic fixtures may stabilize CI only after real replay establishes semantics. Missing or changed evidence stops the work, ordinary/default Claude Code remains supported, and the literal local alternate-Claude corpus is excluded.

## Answer

1. Token support exists in the schema, but the live Copilot adapter reads an obsolete process-log shape while current `events.jsonl` files already carry message output counts, cumulative cost checkpoints, partial compaction buckets, model observations, and final shutdown ledgers.
2. The preserved Harness refs prove the user-visible break: every ref mapped to the five authorized Copilot cases has no token-bearing turns and records every turn duration as zero, despite the matching vendor files carrying usage and timestamp/correlation evidence.
3. Copilot duration repair is partially exact: `turn_start.interactionId` never equals `turn_end.turnId`, while matching `turnId` exists on a subset of starts/ends in every real case. That subset can be measured; every unmatched turn must remain unknown with a reason.
4. Standard-Claude evidence is a positive control, not a substitute for the excluded dark corpus: all five transcript identities are valid, transcript directories match at least one recorded cwd, repeated usage lines require message-id deduplication, and two cases demonstrate mixed-model intervals. Two standard cases also map to measured durable refs.
5. Data disappears or is masked after capture because session evidence is buffer-only, fleet enrichment runs only for roster orphans, and first-location precedence lets an unmeasured ref beat a measured ledger.
6. Durable ref rewriting correctly preserves the event stream but drops prior plan attribution because the rolled manifest stores no plans and `readRolledRef()` reconstructs an empty plan set.
7. Repair is a coupled contract change: capture, nullable duration, OTLP reconstruction, per-field source/model provenance, durable joins, lifecycle/coverage state, readers, schemas, renderers, and privacy gates must move together.
