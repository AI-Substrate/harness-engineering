# Research Dossier: `harness telemetry mark` verb

**Generated**: 2026-07-05T08:20:00Z
**Query**: "How does telemetry segment emission, the semantic-event layer, the guard precedent, and cost aggregation work today — so a new `harness telemetry mark` verb emits a shape-guarded, counts-only self-attestation onto the caller's own lane, attribution-visible but cost-excluded?"
**Effort**: Standard (3 parallel workers)
**Tools**: Standard
**Evidence**: 9 current sources · 0 historical (design settled in-conversation; plan 050 is live code, cited as current)

## Answer

1. A new `harness telemetry` subverb registers as a pure additive `telemetry.command('mark')…​.action()` block in `registerTelemetryAct` — same `deps`, same `formatOk`/`exitWithEnvelope` envelope as every sibling (F-01).
2. There is **no mutable "current segment."** Segments are append-only per-command files written by an auto-capture *preamble* that runs BEFORE each eligible command, keyed to the harness session id from an env var. `harness telemetry mark` therefore already triggers its own preamble segment; the open question is how mark's semantic payload gets INTO the `event_stream` (F-02).
3. The semantic payload field is `Segment.event_stream: Event[]` — a **closed discriminated union** keyed by `kind`, allowlist-by-construction (no free-form field anywhere). A marker is a new `Event`; adding a kind is four coordinated edits + a schema-version bump (F-03).
4. The existing counts-only semantic marker to model on is the **`artifact` event (plan 050)**: closed `counts` (`ArtifactCountKey`) + `enums` (`ArtifactEnumKey`) vocab. But every existing semantic event (`artifact`, `command_exit`, `checks`) is **auto-DERIVED** from repo state / command envelope — none is agent-invoked, so `mark` has no exact twin (F-04).
5. **The annotation-vs-work distinction already exists** at the event level: `artifact`/`flow_log` are excluded from all gap/time/token math by a hardcoded kind filter (`rollup.ts:187-189`), and `laneSemantics` reads `artifact` events as the *attribution* channel — structurally divorced from cost (F-05).
6. Cost double-counting is avoided by three independent mechanisms; the safe contract is a mark whose segment `tokens` is `null` AND whose event kind is non-`turn` AND is added to the rollup exclusion list. `segment.command` is **NOT** a consumer filter key, so exclusion must ride the event-kind mechanism, never a command-name filter (F-06).
7. The reusable input guard is the `^[a-z][a-z0-9-]*$` slug family + the `isIdShapedValue`/`ENV_VALUE_MAX_LEN` value-shape guard — the exact "shape guard, not allowlist" posture the design cites (F-07). `harness observe` is a silent sibling but the WRONG template — it writes an agent-bucketed markdown buffer, not a session segment (F-08).
